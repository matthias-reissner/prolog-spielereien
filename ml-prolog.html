Temperatur-Klassifikation mit Tau Prolog

Ein einfacher 1-NN-Klassifikator ordnet eine Temperatur anhand der ähnlichsten beschrifteten Trainingsdaten einer Klasse zu.

So funktioniert es: Das Modell berechnet den Abstand zu jedem Trainingswert. Die Klasse des nächstgelegenen Werts wird als Vorhersage verwendet.
Gib eine Temperatur ein und starte die Klassifikation.

Ganze Zahl von 0 bis 35. Die Vorhersage basiert auf dem ähnlichsten Trainingswert.
